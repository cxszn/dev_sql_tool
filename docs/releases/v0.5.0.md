# Migration SQL Studio v0.5.0

Windows x64 便携版。使用 PHP 的 `up()` 和静态 `data()` 编写 PostgreSQL 16 / 18 SQL，也可将现有 SQL 转回可编辑 PHP，并在写入前核对往返语义。

## 下载与启动

- `Migration-SQL-Studio-0.5.0-win32-x64.zip`：完整桌面客户端，包含 CLI、MCP 和 PHP IDE 提示包。解压整个目录后运行 `Migration SQL Studio.exe`，无需额外安装 Node.js、PHP 或 PostgreSQL。
- `SqlStudio-IDE-SDK-0.5.0.zip`：单独的 PHP IDE 提示包，适合已有客户端的项目使用。放在迁移输入目录之外，使用 `SqlStudio` 命名空间；VS Code/Cursor 可打开包内 `sql-studio.code-workspace`。
- `SHA256SUMS.txt`：上述两个 ZIP 的 SHA-256 校验值。PowerShell 可用 `Get-FileHash <文件> -Algorithm SHA256` 核对。

仓库为私有时，下载需要具备仓库访问权限的 GitHub 账号。

## 本版功能

- PHP ↔ PostgreSQL 16 / 18 双向静态转换；每份 SQL 对应一份同名 PHP。
- 支持结构、注释、索引、外键、序列起点和逐行初始化数据。
- 默认检查源文件和输出文件的 SHA-256；已登记文件改动会中断，有意重新生成时保留备份。
- 自有 `SqlStudio` PHP 声明包，提供中文说明、参数提示、跳转与链式补全。兼容读取原 Hyperf/Illuminate 写法。
- 桌面模板页可导出 IDE 提示包；提供 10 个 MCP 工具、3 个资源、2 个提示词，以及 sql 编写助手技能与智能体说明。
- 修复浮点字段仅提供 `places` 命名参数时的解析错误。

## CLI 与 MCP

命令行使用便携目录内的 `migration-sql.cmd --help`。

MCP 可从客户端「AI 接入」复制当前安装路径的配置；也可运行 `生成MCP配置.cmd`，生成解压位置对应的 `MCP配置.json`。已有不同配置不会覆盖；移动目录后重新获取配置。无需提供 API Key。

## 验证与使用边界

已完成自动化回归、Windows 便携包 CLI/MCP 检查和解压到不同目录的可移植性验证。IDE 提示通过 Intelephense 语言服务验证；不等同于 IntelliJ IDEA 界面验收。

本工具只生成文件，不执行 PHP 或数据库 SQL。SQL 解析及往返语义比较不等同于真实数据库导入。源脚本中的 DROP 会保留并提示，执行这些 SQL 可能删除原表数据。

已有反向转换清单可能因编译器升级触发文件保护。先预览；仅在明确需要重新生成时关闭保护，工具会保留旧文件备份。
